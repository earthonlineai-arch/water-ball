# Water Polo · 清透水球

基于原生 JavaScript 与 WebGL 2 的清透水球交互展示，支持水蓝色折射材质、动态涟漪、惯性拖拽和体积守恒的水滴融合。材质资源全部本地内嵌，无第三方前端框架和远程资源依赖，适用于网页视觉展示与交互设计。

## 效果与交互

- 不规则主水球持续流动、扭曲，并随水滴汇入产生波动；点击球体可触发向外扩散的涟漪。
- 按住主球向外拖动，可逐渐拉出随机大小的水滴；水颈拉长后断开，水滴可自由拖动并产生柔和惯性拉伸。
- 拖动水滴碰到其他水滴时连续粘连融合，按体积守恒计算新球大小；松手后自动返回主球，经历两次递减回弹后汇入。
- 周围随机生成水滴向主球汇聚，并保留生成间距与移动避让限制。
- 优先使用 Worker / OffscreenCanvas 渲染；失败后尝试相同材质的页面 WebGL 渲染。采用有界帧队列及隐藏页面暂停机制，避免任务积压。
- 完整动态渲染确认失败后，才展示同材质烘焙的大球和五颗渐显小球；六个元素以 CSS 缓慢呼吸缩放，大球幅度较小。

## 快速运行

在项目目录执行：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

- 水球展示：http://127.0.0.1:8080/water-ball.html
- 登录页示例：http://127.0.0.1:8080/water-login.html

无需安装 npm 依赖。两份 HTML 可直接部署到静态服务器；完整动态效果需要浏览器支持 WebGL 2。登录页仅为界面展示，不含账号认证与服务端业务逻辑。

## 修改与构建

修改 `source/` 内的文件后，执行：

```sh
python build.py
```

构建脚本仅使用 Python 标准库，将源码及材质重新内嵌到 `water-ball.html`。不修改源码时，可直接使用已构建的 HTML，无需执行构建。

| 文件 | 用途 |
| --- | --- |
| `water-ball.html` | 自包含的水球展示页 |
| `water-login.html` | 通过 iframe 引用水球页的登录布局示例 |
| `build.py` | 无额外依赖的构建脚本 |
| `source/water-ball.template.html` | 页面结构、样式和静态水滴布局 |
| `source/water-runtime.js` | 水滴模拟、拖拽融合、交互和加载恢复 |
| `source/water-gpu.js` | GPU 渲染器、Worker 与帧队列 |
| `source/water-fusion.frag` | 水体材质、折射和曲面融合着色器 |
| `source/water-aa.frag` | 抗锯齿着色器 |
| `source/*.webp`、`source/*.png` | 本地材质与静态展示资源 |

## 当前参数

- 动态渲染像素预算 880,000，目标帧率上限 24fps。
- 自动水滴生成的目标频率为初始版本的 1.44 倍；实际生成同时受容量及间距限制。
- 受限模式大球呼吸最大放大 2.7%，五颗小球最大放大 16.5%，节奏略微错开。
- 法线和环境纹理合计约 286 KiB，构建后的水球页约 592 KiB。

受限提示：当前浏览器功能受限，无法显示页面动态效果。
